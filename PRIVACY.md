# Demo privacy and scope

This export does not need or contain an API key. It contains fictional seed activity, public club references, the project branding, and the creator's intended public attribution. It does not include the original hosted database, sign-in sessions, private account information, environment files, or the original workspace's Git history.

The application makes no API requests for community activity. Fonts and logo images are bundled locally. Instagram references are ordinary external links opened only when selected. GitHub Pages serves the website's static files; it does not store this demo's posts or conversations.

Demo activity and uploaded photos are saved in IndexedDB on the visitor's device. Some drafts and interface preferences use browser storage. Nothing typed or uploaded is added to the repository. Other people using the same browser profile may be able to see its saved demo activity. Clearing this site's browser data resets it. Saving can fail when browser storage is disabled, full, or temporary in private browsing.

Switching demo profiles is for exploration, not secure login. All accounts, conversations, leadership assignments, and events are fictional. Club names and logos come from public Instagram profiles. TAMS Connect is a student project made by Subhas Angara, not an official UNT TAMS service.

A public GitHub repository exposes its uploaded files. Upload this prepared folder only; do not add credentials, real student records, private messages, or personal photos to the repository. A real shared community would need a backend, authenticated accounts, privacy controls, and further testing before launch.
